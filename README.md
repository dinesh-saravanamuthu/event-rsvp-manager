# Event RSVP Manager

A standalone event and guest management frontend built with HTML, CSS and JavaScript.

## Features
- Create events with date, time, venue and description.
- Add guests to an event.
- Track guest RSVP status: Pending, Confirmed or Declined.
- Search events and filter guest responses.
- View event, guest and confirmed RSVP totals.
- Save event and guest data in browser localStorage.

## Run
Extract the ZIP and open `index.html` in a modern browser.

## Notes
This is a frontend demo. Guest invitations are recorded locally; email sending, authentication, QR check-in, backend services and database storage are not configured.
